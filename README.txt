PUBLIKA WEBSITE - GITHUB PAGES

1. Download product photos once (they are saved into assets/remote/):
   Windows: double-click download-images.bat
   Mac/Linux: bash download-images.sh
2. Upload EVERYTHING in this folder (including the hidden .nojekyll file and the assets folder) to the root of your GitHub repository.
3. In the repo: Settings > Pages > Deploy from branch > main / (root).
4. Your site opens at index.html, which forwards to Home.dc.html.
